# Progress report

**Name:** Walter Hsieh

## Done

- **Team repo.** Private repo at github.com/WalterHsieh0713/more-than-a-hack-2027. Metrica's
  repo is the `upstream` remote, so `git pull upstream main` picks up their doc changes.
- **Shared match format** (`src/match.py`). Every match, whether an open training game or
  BAR-ATH, loads into one `Match`: positions in metres, NaN where an object isn't seen, labels in
  the scorer's codes (H=0, A=1, D=2, X=3). Code that runs on the training games runs unchanged on
  BAR-ATH.
- **Scoring** (`src/scoring.py`). Wraps the official `evaluation/possession_metrics.py` without
  changing it. `pooled()` joins several matches end to end and scores them together, which is the
  closest match to how the full-match leaderboard behaves.
- **Baseline on that format** (`src/baseline.py`). Labels each frame with the team of the player
  nearest the ball, then smooths with a majority vote. This is the reference to beat on the
  training games.
- **IDSSE training data** (`src/external/idsse.py`). 7 Bundesliga matches with per-frame
  ball-alive and possession labels, approved by the organisers in issue #16. All 7 downloaded,
  parsed and cached as `.npz`.
- **Summary script for the training games** (`src/external/describe.py`). Label shares,
  possession lengths, how many possessions are very short, how the ball behaves while dead. Reads
  IDSSE only, never BAR-ATH.

## Blockers / notes

- **Setup for a fresh clone.** Get the gated data via DATA.md and unpack it into `data/` (layout
  in `data/README.md`). Then run `python -m src.external.idsse download` followed by
  `python -m src.external.idsse cache`. Nothing under `data/` or `external_data/` is in git.
- **Rules that disqualify:** no hand labels or hand corrections on this match, no training or
  tuning on the public GT window (frames 11185-18684), no human-produced data about this match.
  See `CLAUDE.md`.
- **Hosted LLMs:** the T&Cs forbid sending match data or extracts to them. Scripts that print
  BAR-ATH output get run by a person, not pasted into Claude/ChatGPT.
- No model yet; nothing has been scored against the baseline's spellF1 of 0.2433.
