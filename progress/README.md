# Progress reports

One file per report, named `YYYY-MM-DD-firstname.md` (e.g. `2026-11-01-walter.md`). The date is
the day the report was written. The first name keeps two people's reports on the same day apart.

Copy [TEMPLATE.md](TEMPLATE.md) to start a new one. Every report opens with the author's name and
the date, then three sections: what got done, what's next, and anything blocking or worth flagging.

Never paste match numbers (BAR-ATH scores, label counts, frame-level output) into a report that
might end up in a hosted LLM. Scores on the open IDSSE games are fine.
